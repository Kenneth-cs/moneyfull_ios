## 二、方向1：AI整理助手（P0 核心功能）

### 2.1 功能概述

为导入的历史账单提供AI智能分析和整理能力，帮助用户快速将「历史账单」项目中的数据分配到对应项目。

### 2.2 用户场景

```
用户从随手记导入1000条历史数据 → 全部暂存在「历史账单」
→ 点击「AI整理」按钮
→ AI分析发现：
   · 2024年7月有大量餐饮+交通+住宿集中在新疆 → 建议创建「新疆旅行」项目
   · 2024年1-3月有多笔家居/建材消费 → 建议归入「装修」项目
   · 其余日常消费 → 归入「日常收支」
→ 用户确认/调整方案 → 批量执行整理
```

### 2.3 技术方案

**复用现有能力**：
- LLMService：调用AI分析账单规律
- MemoryRule：记录用户偏好，提升后续整理准确率
- AppStore：批量移动交易记录

**核心流程**：

```
┌─────────────────────────────────────────────────────────┐
│  1. 收集数据                                             │
│     · 获取「历史账单」项目的所有交易                       │
│     · 提取日期、分类、金额、备注等特征                     │
├─────────────────────────────────────────────────────────┤
│  2. AI分析                                               │
│     · 时间聚类：识别时间段内的集中消费                     │
│     · 分类聚类：识别相似分类的消费模式                     │
│     · 关键词提取：从备注中提取地点、事件关键词             │
├─────────────────────────────────────────────────────────┤
│  3. 生成方案                                             │
│     · 建议创建的新项目（名称、时间范围、描述）             │
│     · 每条记录的归属建议                                  │
│     · 置信度评分                                         │
├─────────────────────────────────────────────────────────┤
│  4. 用户确认                                             │
│     · 展示整理方案预览                                    │
│     · 支持调整项目名称、移动记录                          │
│     · 确认后批量执行                                      │
└─────────────────────────────────────────────────────────┘
```

### 2.4 UI设计

**入口**：「历史账单」项目详情页 → 右上角「AI整理」按钮

│  │ 餐饮×12 交通×8 住宿×5 ...   │  │
│  └──────────────────────────────┘  │

## 三、方向2：周期账单自动记录（P1）

### 3.1 功能概述

支持用户设置周期性账单（房租、话费、会员费等），到期自动提醒或自动记录。

### 3.2 用户场景

```
用户设置：每月1号 → 房租 ¥3000 支出
设置完成 → 每月1号自动创建交易记录
用户只需确认或修改
```

### 3.3 技术方案

**现有基础**：
- Models.swift 已有 `RecurringBill` 模型
- 需要添加自动记录触发逻辑

**核心流程**：

```
┌─────────────────────────────────────────┐
│  1. 用户设置周期账单                     │
│     · 名称、金额、分类                   │
│     · 周期：每日/每周/每月/每年          │
│     · 下次到期日                         │
│     · 是否自动记录                       │
├─────────────────────────────────────────┤
│  2. 系统检测                             │
│     · App启动时检查到期账单              │
│     · 后台定时检查（Background Tasks）   │
├─────────────────────────────────────────┤
│  3. 执行记录                             │
│     · 自动模式：直接创建交易记录         │
│     · 提醒模式：推送通知，用户确认后记录 │
├─────────────────────────────────────────┤
│  4. 更新状态                             │
│     · 记录lastRecordedAt                 │
│     · 计算下次到期日                     │
└─────────────────────────────────────────┘
```
