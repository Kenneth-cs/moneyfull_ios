## Phase 1：UI 骨架（Mock 数据，先看效果）

**目标：** 用假数据把所有视觉效果跑通，能在真机/模拟器上切换总览↔日历。

### Step 1.1 — Hero 卡片结构改造

**改动文件：** `DashboardView.swift`

- 新增 `HeroTab` enum（`.overview` / `.calendar`）
- 新增 `@State private var heroTab: HeroTab = .overview`
- 在 Hero 卡片顶部加入 Segmented Control（总览 / 预算日历）
- 顶部右侧加 `预算 ¥6,000` 文字（只在日历 tab 显示）
- 切换时 `withAnimation(.easeInOut(duration: 0.25))`
- IP（GreetingBubbleView + GreetingCapybaraView）加 `.opacity(heroTab == .overview ? 1 : 0)`
- 维度选择下拉箭头：切到日历时 `.opacity(0)` + `.disabled(true)`

### Step 1.2 — 总览 Tab 补全预算进度区

**在现有 Hero 卡片「支出金额」和「收入/储蓄卡片」之间，插入：**

- 标题「预算已用」
- 单根进度条（用 Mock 值 54%，绿色已用，淡绿色未用，高度 8px，满圆角）
- 进度条下方：左侧「本月已过 53% · 节奏正常」，右侧浅绿色胶囊「剩余 ¥2,384」
- 胶囊先 Mock，不接交互

### Step 1.3 — 新建 `BudgetCalendarView` 组件

**新建文件：** `moneyfull_ios/Components/BudgetCalendarView.swift`

内部结构（全部 Mock 数据）：

```
BudgetCalendarView
 ├── 月份导航行（< 2026年9月 > + 节奏状态胶囊）
 ├── 星期表头（日一二三四五六）
```

## Phase 2：数据层（UserDefaults + AppStore 扩展）

**目标：** 建立计算引擎，不碰 SwiftData Schema。

### Step 2.1 — 月预算存取

**新建文件：** `moneyfull_ios/Services/HomeBudgetService.swift`

```swift
// 存取：UserDefaults key = "homeBudget_2026_09"
static func budget(year: Int, month: Int) -> Double?
static func setBudget(_ amount: Double, year: Int, month: Int)
```

### Step 2.2 — AppStore 新增每日支出聚合

**在 `AppStore.swift` 扩展新增：**

```swift
// 返回 [日期序号: 当日支出合计]，如 [1: 168, 2: 190, ...]
func dailyExpenses(year: Int, month: Int) -> [Int: Double]

// 返回今日支出合计
func todayExpense() -> Double
```

### Step 2.3 — 预算计算模型

**在 `HomeBudgetService.swift` 内实现第十七节所有公式：**

```
dailyBudget / remainingBudget / budgetProgress
timeProgress / paceDifference / averageDailyExpense
projectedMonthlyExpense / dynamicDailyBudget
todayRemainingSpend / dailyDifference
```

以及节奏状态判断（五档 + 超预算）、月初 ≤7天保护。

## Phase 3：UI 联通真实数据

**目标：** 把 Phase 1 的 Mock 值全部替换为 Phase 2 的真实计算结果。

### Step 3.1 — BudgetCalendarView 接真实数据

- 从 `AppStore.dailyExpenses()` 读每天金额
- 从 `HomeBudgetService.budget()` 读月预算
- 底部摘要五个指标全接真实值
- 「本月预计」加 ≤7天的 `--` 判断

### Step 3.2 — 总览进度条接真实数据

- 预算进度 %、时间进度 %、节奏状态文案
- 剩余预算胶囊数字

### Step 3.3 — 预算设置 Bottom Sheet

- 点击「剩余 ¥XXX」胶囊 → 弹出设置/修改月预算的 Sheet
- 已设置状态：显示当前值 + 修改按钮
- 未设置状态：引导设置，设置完立即刷新首页所有指标
- 设置完成调 `HomeBudgetService.setBudget()`

### Step 3.4 — 日历点击交互

- 点击某天 → 底部三个指标切换为该天的数据
- 今日自动默认高亮

### Step 3.5 — 翻月逻辑

- 当前月：完整逻辑（截至今日 / 本月预计 / 节奏状态）
- 历史月：改为「整月支出 / 月预算 / 结余 or 超预算」
- 未来月：显示「暂无消费记录」或「设置X月预算」
