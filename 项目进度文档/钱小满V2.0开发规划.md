# 钱小满 (Moneyfull) v2.0 - AI Native 升级开发规划

## 阶段一：核心架构与 AI 基础体验 (Phase 1 - MVP)
**目标：** 跑通最核心的“语音/文字 -> LLM 解析 -> 结构化数据”链路，建立 Agent 记忆模型。

### 1. 数据模型升级 (SwiftData)
*   [ ] 在 `Transaction` 模型中新增 `source` 字段 (枚举：manual, voice, image, auto)。
*   [ ] 新增 `ChatHistory` 模型 (id, role, content, timestamp)。
*   [ ] 新增 `MemoryRule` 模型 (id, keyword, targetCategoryName, targetProjectName, weight, createdAt)。

### 2. 核心 AI 服务层 (Agent Service)
*   [ ] 封装 `LLMService`：对接 DeepSeek/千问 API，处理网络请求。
*   [ ] 编写 **System Prompt**：定义“小满”人设，规定 JSON 输出格式。
    *   **Prompt 优化：** 强制要求 AI 提取并返回“一级分类 (groupName)”和“二级分类 (name)”。如果用户提到的二级分类不存在，AI 应返回 `{"status": "suggest_new_category", "suggested_category": "咖啡", "parent_group": "餐饮"}`。
*   [ ] 实现 **Context Manager**：
    *   读取本地 `Category` 和 `Project` 列表注入 Prompt。
    *   读取 `MemoryRule` 注入 Prompt。
    *   读取最近 5 条 `ChatHistory` 注入 Prompt。
*   [ ] 封装 `SpeechService`：使用 `SFSpeechRecognizer` 实现语音转文字。

### 3. UI 重构与交互
*   [ ] **首页布局调整：** 
    *   在首页顶部数据看板（收入/储蓄下方）新增一个横向的 `+ 记一笔` 长按钮，作为传统记账入口。
*   [ ] **TabBar 重构：** 
    *   底部中间替换为“AI 助手”按钮，使用专属的麦克风 Icon 设计。
    *   支持长按录音、短按打开 Chat。
*   [ ] **AI 对话页面 (Chat UI)：**
    *   参考设计图搭建 UI，并进行 iOS 原生尺寸适配（处理安全区域、键盘遮挡、气泡最大宽度等）。
    *   实现类似微信的聊天气泡流。
    *   实现底部的语音/键盘切换输入框。
*   [ ] **记账确认卡片 (Transaction Card)：**
    *   在 Chat UI 中，解析 LLM 返回的 JSON，渲染为可交互的卡片。
    *   支持点击修改分类/项目。
    *   **新分类创建交互：** 如果 LLM 建议了新二级分类（如“咖啡”），卡片上显示 `✨ 咖啡 (新)`。用户点击确认保存时，底层自动在“餐饮”一级分类下创建“咖啡”分类并入账。
    *   **记忆捕获：** 当用户在卡片上修改了 AI 的分类，触发写入 `MemoryRule`。
    *   **实现 3 秒倒计时自动保存入账的逻辑。**
    *   **包含“确认”和“取消”按钮，支持手动立即保存或放弃。**

## 阶段二：视觉解析与系统级整合 (Phase 2)
**目标：** 引入多模态能力，打破 App 边界，实现“最懒场景”。

### 1. 视觉记账 (VLM / OCR)
*   [ ] 封装 `VisionService`：使用 iOS 原生 `Vision` 框架提取图片文本。
*   [ ] 扩展 `LLMService`：支持将 OCR 文本发给 LLM 解析账单。
*   [ ] 在 Chat UI 中增加“相册/拍照”入口，支持图片记账。

### 2. iOS 系统整合 (App Intents & Widgets)
*   [ ] 开发 `RecordTransactionIntent`：允许通过 Siri 语音直接记账。
*   [ ] 开发锁屏小组件 (Lock Screen Widget)：一键唤起 App 并直接进入录音状态。
*   [ ] 编写“轻点背面”快捷指令配置教程页面。

**目标：** 照顾老用户习惯，探索被动记账。

### 1. 传统记账面板优化
*   [ ] 实现“✨ 智能推荐”分类行（根据时间/历史习惯动态推荐 3 个分类）。
*  在传统的记一笔页面，点击空白处或者滑动页面，键盘收起来

### 2. 自动化与洞察
