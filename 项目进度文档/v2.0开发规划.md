# v2.0 开发规划 & 信任基石建设

> 最后更新：2026-05-02

---

## 一、核心理念：信任是记账 App 的生死线

记账 App 的用户最敏感的不是功能多寡，而是**「数据会不会丢」**。用户每天花时间记录的每一笔账，都是个人财务隐私和时间投入。一旦数据丢失，用户会立刻卸载且不会回来。

**v2.0 的核心目标：让用户无条件信任这个 App 的数据安全性。**

---

## 二、信任基石 — P0 优先级

### 1. 数据本地存储保障（SwiftData）

**现状**：SwiftData 存储已实现，但缺少异常保护。

- [ ] **数据完整性校验**：App 启动时校验 SwiftData 容器是否正常加载，异常时展示恢复引导而非白屏崩溃
- [ ] **写入确认机制**：`addTransaction()` / `addProject()` 写入后做一次 `save()` 确保立即落盘，而非依赖 SwiftData 自动保存时机
- [ ] **数据库健康检查**：ProfileView 新增「数据状态」入口，展示当前数据条数、最后写入时间、存储占用空间

### 2. iCloud 云端备份（基础版）

> 虽然原定「达到信心线再做 iCloud」，但对记账用户来说，**「换手机/丢手机数据丢失」是第一顾虑**。基础备份不等于实时同步，成本低但信任价值极高。

- [ ] **iCloud 备份方案选型**：使用 `NSUbiquitousKeyValueStore`（轻量键值对）或 CloudKit（结构化数据）实现备份
  - 推荐方案：**CloudKit 私有数据库** — 只备份当前用户数据，不涉及共享
  - 数据结构：将 SwiftData 的 `Project` / `Transaction` / `Category` 序列化为 CKRecord
- [ ] **自动备份逻辑**：
  - 每次 App 进入后台时自动触发增量备份
  - 备份频率：每天最多 1 次完整备份 + 多次增量
  - 备份内容：所有 Project + Transaction + Category 数据
- [ ] **手动备份入口**：ProfileView 新增「立即备份」按钮，展示上次备份时间
- [ ] **恢复流程**：
  - 新设备首次安装时检测 iCloud 备份，弹窗引导恢复
  - ProfileView 新增「从 iCloud 恢复」入口（需二次确认弹窗）
  - 恢复前预览：显示备份时间和数据条数，让用户确认再恢复
- [ ] **备份状态展示**：ProfileView 显示「上次备份：今天 14:30」「备份大小：2.3 MB」

### 3. 埋点时间戳修正

**现状**：`AnalyticsManager.trackEvent` 中的 `ISO8601DateFormatter` 默认输出 UTC 时间（末尾 `Z`），后台直接展示会比北京时间晚 8 小时。

- [ ] **设置北京时间**：formatter 指定 `Asia/Shanghai` 时区，输出带 `+08:00` 后缀，后台无需再做时区转换
  ```swift
  let formatter = ISO8601DateFormatter()
  formatter.timeZone = TimeZone(identifier: "Asia/Shanghai")
  ```
- [ ] **端点逻辑保持不变**：DEBUG → `localhost:3000`（模拟器本地调试），Release → 正式云服务器，当前逻辑正确无需调整

## 三、P1 — 商业化闭环

### 4. 分类持久化

- [ ] `AppStore` 实现 `seedDefaultCategories()`：首次启动时将 11 个系统预设类目写入 SwiftData（餐饮、交通、购物、娱乐、住房、医疗、教育、通讯、服饰、日用、其他）
- [ ] `AppStore` 实现 `fetchCategories()`：从数据库读取所有 Category
- [ ] `AddRecordView` 分类列表改为从 `store.categories` 读取，移除底部硬编码 `categories` 数组

### 5. StoreKit 2 IAP

- [ ] 新建 `StoreManager`：StoreKit 2 实现 Pro 买断（¥38）购买 + 恢复购买
- [ ] 注入为 EnvironmentObject，全局可访问 `storeManager.isPro`
- [ ] 实现 `ProUpgradeView` 付费墙 UI

### 6. 免费层限制

- [ ] `AppStore.addProject()` 中检查：非 Pro 用户最多 3 个项目（不含「日常收支」）
- [ ] 超限时弹出 `ProUpgradeView`
- [ ] 免费用户可用：完整记账 + 通用类目 + 自定义类目 + 最多 3 个项目 + 基础报表

### 7. 隐私政策页

- [ ] ProfileView 加入隐私政策入口
- [ ] WebView 加载外链或本地 HTML
- [ ] App Store 审核必需
