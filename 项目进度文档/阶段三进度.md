### 2. 键盘收起优化

**文件**：[AddRecordView.swift](file:///Users/cs/Desktop/CS/AI/moneyfull_ios/moneyfull_ios/Views/AddRecordView.swift)

**实现方案**：
- 使用 `.simultaneousGesture(DragGesture())` 检测滑动手势
- 设置 `minimumDistance: 20` 避免误触
- 检测垂直滑动距离超过 10 时触发收起
- 点击空白区域也可收起键盘

**交互流程**：
```
用户滑动页面 → 检测 DragGesture → 判断垂直距离 > 10 → showKeypad = false
用户点击空白 → onTapGesture → showKeypad = false
点击金额区 → onTapGesture → showKeypad = true
```

### 3. 周期账单模型

**文件**：[Models.swift](file:///Users/cs/Desktop/CS/AI/moneyfull_ios/moneyfull_ios/Models/Models.swift)

**数据结构**：
```swift
@Model
final class RecurringBill {
    var id: UUID
    var name: String              // 账单名称（如"房租"）
    var amount: Double            // 金额
    var rawType: String           // expense/income
    var categoryName: String      // 分类名称
    var categoryIcon: String      // 分类图标
    var categoryColorHex: String  // 分类颜色
    var projectID: UUID?          // 关联项目
    var rawFrequency: String      // daily/weekly/monthly/yearly
    var nextDueDate: Date         // 下次到期日
    var isAutoRecord: Bool        // 是否自动记账
    var isActive: Bool            // 是否启用
    var note: String              // 备注
    var createdAt: Date           // 创建时间
    var lastRecordedAt: Date?     // 上次记账时间
}
```

**周期频率枚举**：
```swift
enum RecurringFrequency: String, Codable {
    case daily = "daily"
    case weekly = "weekly"
    case monthly = "monthly"
    case yearly = "yearly"
}
```

**计算下次到期日**：
```swift
func calculateNextDueDate() -> Date {
    let calendar = Calendar.current
    switch frequency {
    case .daily:   return calendar.date(byAdding: .day, value: 1, to: nextDueDate)
    case .weekly:  return calendar.date(byAdding: .weekOfYear, value: 1, to: nextDueDate)
    case .monthly: return calendar.date(byAdding: .month, value: 1, to: nextDueDate)
    case .yearly:  return calendar.date(byAdding: .year, value: 1, to: nextDueDate)
    }
}
```
