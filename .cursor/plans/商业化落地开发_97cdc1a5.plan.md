## Phase 1 — StoreKit 2 基础层（新建文件）

**新建 `Services/StoreManager.swift`**

负责产品加载、购买、订阅状态验证、燃料包计数。

Product ID 规划：

- `com.moneyfull.premium.monthly` — 月卡 ¥9.9
- `com.moneyfull.premium.annual` — 年卡 ¥68
- `com.moneyfull.premium.lifetime` — 终身 ¥198
- `com.moneyfull.fuelpack.200` — 燃料包 200 次 ¥6
- `com.moneyfull.fuelpack.500` — 燃料包 500 次 ¥12

核心职责：

- `@Published var isPremium: Bool` — 订阅状态（监听 `Transaction.updates`）
- `@Published var fuelCredits: Int` — 燃料包剩余（`UserDefaults` 持久化）
- `purchase(_ product:)` — 触发 StoreKit 购买
- `restorePurchases()` — 恢复购买
- `presentOfferCodeSheet()` — 兑换码入口（一行代码）
- 启动时调用 `verifyCurrentEntitlements()` 恢复本地状态

注入方式：在 [`moneyfull_iosApp.swift`](moneyfull_ios/moneyfull_iosApp.swift) 通过 `@StateObject` 注入，`environmentObject` 传递全局可用。

## Phase 2 — AI 调用分级限流（改动现有文件）

**修改 [`Views/AIChatView.swift`](moneyfull_ios/Views/AIChatView.swift)**

将当前硬编码的 `dailyLimit = 15` 改为按订阅状态动态配置：

```swift
// 改前
private static let dailyLimit = 15

// 改后
private var dailyLimit: Int {
    if storeManager.isPremium { return 100 }
    return 10  // 免费版
}
```

燃料包叠加逻辑（`isLimitReached` 计算属性）：

```swift
private var isLimitReached: Bool {
    let base = dailyUsageCount >= dailyLimit
    if base && storeManager.fuelCredits > 0 { return false }  // 燃料包兜底
    return base
}
```

**修改 [`Services/LLMService.swift`](moneyfull_ios/Services/LLMService.swift)**

每次 API 返回后累加 Token：

```swift
// 解析响应后
if let usage = responseData.usage {
    TokenMonitor.shared.record(tokens: usage.totalTokens)
}
```

新建轻量工具类 `Utils/TokenMonitor.swift`，按 userId + 日期写入 `UserDefaults`，开发调试时可在控制台打印成本。

## Phase 3 — 项目数量门控 + Grandfathering（改动现有文件）

**Grandfathering 检测时机**：App 首次升级到含商业化的版本时执行一次，在 [`Models/AppStore.swift`](moneyfull_ios/Models/AppStore.swift) `initialize()` 中：

```swift
// 仅执行一次（UserDefaults flag 保护）
if !UserDefaults.standard.bool(forKey: "grandfatheringChecked") {
    let count = projects.filter { !$0.isActiveProject }.count
    if count > 3 {
        UserDefaults.standard.set(true, forKey: "hasGrandfatheredProjects")
    }
    UserDefaults.standard.set(true, forKey: "grandfatheringChecked")
}
```

**项目创建门控**：在 [`Views/NewProjectView.swift`](moneyfull_ios/Views/NewProjectView.swift) 保存时判断：

```swift
var canCreateProject: Bool {
    if storeManager.isPremium { return true }
    if UserDefaults.standard.bool(forKey: "hasGrandfatheredProjects") {
        return true  // 老用户：已有超额项目，保留权益但仍允许继续创建（读保留，新建也保留）
        // 注：也可改为"仅保留，不允许再新建"——取决于产品决策
    }
    let userProjects = projects.filter { !$0.isActiveProject }
    return userProjects.count < 3
}
```

> **产品决策点**：老用户是否允许继续新建第 N+1 个项目（在已有超额基础上）？或仅保留现有、禁止新建？方案未明确，需要确认后再实现。

## Phase 4 — Paywall & 场景化升级 UI（新建 + 改动文件）

**新建 `Views/PaywallView.swift`**

- 展示月卡 / 年卡 / 终身三档（年卡主推高亮）
- 「恢复购买」+「兑换码」两个次级入口
- 可作为 `sheet` 或 `fullScreenCover` 弹出

**三个场景化触发点**：

1. AI 额度用完时 — [`Views/AIChatView.swift`](moneyfull_ios/Views/AIChatView.swift) 的 `isLimitReached` 后提示弹层（燃料包 vs Premium 二选一）
2. 新建第 4 个项目时 — [`Views/NewProjectView.swift`](moneyfull_ios/Views/NewProjectView.swift) 保存拦截后弹出 Paywall
3. 预算超 80% 预警时 — [`Views/ProjectDetailView.swift`](moneyfull_ios/Views/ProjectDetailView.swift) 预算进度条到达阈值时弹出提示（Premium ROI 看板预热，暂时只做提示）
