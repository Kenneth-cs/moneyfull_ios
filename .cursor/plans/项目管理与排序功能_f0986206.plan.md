# 项目管理与排序功能实现计划

## 1. 现状分析
- **数据层**：`AppStore.swift` 中已经存在 `sortOrder` 属性以及 `updateProjectSortOrder` 方法，且 `activeProjects` 已经按 `isPinned` 和 `sortOrder` 排序。
- **记一笔页面**：`AddRecordView.swift` 中的“归属项目”已经是横向 `ScrollView`，并直接使用了 `store.activeProjects`。
- **编辑功能**：`EditProjectView.swift` 已经存在，支持修改项目的名称、图标、颜色和预算。
- **结论**：底层数据和关联页面已就绪，我们只需要专注于**入口的添加**和**管理列表页面的开发**。

## 2. 具体修改步骤

### 步骤 1：在项目中心添加入口
**文件**：`moneyfull_ios/Views/ProjectsView.swift`
- 在顶部 Header 区域（目前使用的是 `PageHeader`）右侧添加一个「管理」按钮。
- 考虑到 `PageHeader` 内部写死了铃铛图标，我们可以直接在 `ProjectsView` 中用自定义的 `ZStack` 替换 `PageHeader`，或者修改 `PageHeader` 以支持传入右侧视图。
- 增加 `@State private var showManage = false` 状态，点击「管理」按钮时弹出 `ProjectManageView`。

### 步骤 2：创建项目管理页面
**文件**：`moneyfull_ios/Views/ProjectManageView.swift` (新建文件)
- 创建一个包含 `List` 的视图，用于展示所有进行中的项目。
- **分组展示**：由于 `AppStore` 排序时优先考虑 `isPinned`（如默认的“日常收支”），为了避免用户将非置顶项目拖拽到置顶项目上方导致排序失效的困惑，列表应分为两个 `Section`：
  - `Section(header: Text("置顶项目"))`
  - `Section(header: Text("其他项目"))`
- **拖拽排序**：为两个 Section 的 `ForEach` 分别添加 `.onMove` 修饰符。拖拽完成后，调用 `store.updateProjectSortOrder` 更新对应分组的排序。
- **行视图设计**：
  - 左侧：项目图标（带背景色）。
  - 中间：项目名称。
  - 右侧：显示预算信息（例如“预算: ¥3000”或“未设预算”），文字颜色使用灰色，字号稍小。
- **编辑交互**：点击任意一行，通过 `.sheet` 弹出已有的 `EditProjectView`，实现预算和信息的快捷修改。

### 步骤 3：调整与测试
- 确保在 `ProjectManageView` 中排序后，返回 `ProjectsView` 和进入 `AddRecordView`（记一笔）时，项目的展示顺序能立即同步更新。
- 确保点击列表项能正确拉起 `EditProjectView` 并保存修改。
