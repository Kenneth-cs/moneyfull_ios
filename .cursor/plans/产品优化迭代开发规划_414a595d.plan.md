# 产品优化迭代开发规划

## 1. 首页Tab滑动交互优化
- **目标**: 禁用首页左右滑动切换Tab，恢复系统右滑返回手势。
- **实现**: 修改 `moneyfull_ios/Views/MainTabView.swift`，移除 `TabView` 的 `.tabViewStyle(PageTabViewStyle(indexDisplayMode: .never))` 修饰符。这样 `TabView` 将恢复默认行为（点击切换，不支持滑动），从而不影响子页面的右滑返回。

## 2. 小满IP互动优化
- **目标**: 引入连击检测机制，点击停止后才出气泡文案。
- **实现**: 修改 `moneyfull_ios/Components/CommonViews.swift` 中的 `GreetingMascotView`。
  - 引入防抖机制（Debounce）：每次点击仅增加 `tapCount`，不立即更新 `currentQuote`。
  - 使用 `Task.sleep` (约 0.5s) 延迟触发。如果在延迟期间再次点击，则取消旧任务并重新计时。
  - 延迟结束后，根据累计的 `tapCount` 调用 `generateInteractiveQuote()` 更新文案，并重置计数。

## 3. 账单编辑与删除功能
- **目标**: 在首页最近交易和项目详情账单列表中支持左滑编辑和删除。
- **实现**: 
  - 开发一个通用的 `SwipeActionView` 组件（基于 `DragGesture` 和 `offset`），或者将现有的 `VStack` 列表重构为无样式的 `List` 并使用原生的 `.swipeActions`。
  - 修改 `moneyfull_ios/Views/DashboardView.swift` 中的最近交易列表，为 `TransactionItem` 添加左滑菜单，绑定编辑（弹出 `EditTransactionView`）和删除（弹出二次确认）操作。
  - 修改 `moneyfull_ios/Views/ProjectDetailView.swift`，将 `TimelineTxRow` 的 `.contextMenu` 替换为左滑菜单。

## 4. “记一笔”日期选择器优化
- **目标**: 将日期选择从键盘移出，放到页面顶部独立显示。
- **实现**: 修改 `moneyfull_ios/Views/AddRecordView.swift`。
  - 移除数字键盘中的日历按钮 `KeyButton(icon: "calendar")`。
  - 在金额输入框下方（或上方）增加一个独立的日期选择入口行，点击后唤起现有的 `DatePickerSheet`。

## 5. “记一笔”归属项目与分类层级优化
- **目标**: 归属项目置顶并支持横向滑动快捷选择，支持在设置中自定义排序。
- **实现**: 
  - **数据层**: 修改 `moneyfull_ios/Models/Models.swift`，为 `Project` 模型增加 `var sortOrder: Int = 0` 属性。修改 `AppStore.swift`，在 `fetchProjects` 中加入按 `sortOrder` 排序的逻辑，并新增 `updateProjectSortOrder` 方法。
  - **记一笔页**: 修改 `moneyfull_ios/Views/AddRecordView.swift`，将“归属项目”模块移至“分类”列表上方，并改为 `ScrollView(.horizontal)` 横向排列的卡片样式。
  - **设置页**: 修改 `moneyfull_ios/Views/ProfileView.swift`，在“账户管理”中新增“项目排序”入口。
  - **排序页**: 新增 `ProjectSortingView.swift`，使用 `List` 和 `.onMove` 实现拖拽排序。

## 6. 新建项目图标丰富化
- **目标**: 同步记一笔的图标到新建项目，并分类展示。
- **实现**: 
  - 修改 `moneyfull_ios/Utils/Colors.swift`，将 `CategoryIconLibrary.all` 按主题（如日常、餐饮、交通、购物等）进行分组，提供一个分组后的数据结构。
  - 修改 `moneyfull_ios/Views/NewProjectView.swift`，遍历图标分组，使用 Section Header 分类展示所有图标。

## 7. 全局弹层与按钮UI统一
- **目标**: 统一全局弹层和按钮的品牌色（绿色）。
- **实现**: 
  - 修改 `moneyfull_ios/moneyfull_iosApp.swift`，在 `ContentView()` 上添加全局 `.tint(Color.App.darkGreen)`，使系统原生的 Alert、ConfirmationDialog、DatePicker 等组件的按钮自动变为绿色。
  - 修改 `moneyfull_ios/Views/AddRecordView.swift`，将其顶部的“完成”按钮背景色从 `#546073` 改为 `Color.App.darkGreen`。
